# FLYDIGI Direwolf — animated presentation

Презентация рассчитана на двух выступающих по 4 минуты:

- выступающий 1: слайды 1–5;
- выступающий 2: слайды 6–11.

Фотографии из задания не используются: визуал контроллера сделан как оригинальная SVG-иллюстрация.

## Запуск

```bash
npm install
npm run dev
```

Для статической сборки:

```bash
npm run build
```

Откройте режим Presenter View (`P`) для заметок с текстом выступления и таймером.

## Важно о модели

По фотографиям уверенно определяется бренд FLYDIGI и семейство Direwolf. Точную ревизию (Direwolf, Direwolf 3 или другая версия) лучше сверить по коробке или маркировке, поэтому в слайдах не заявлены спорные характеристики конкретной ревизии.
